# Decision — research-only; correction before a limited trial

The new experiment obtained 69 fresh first final answers from 69 distinct Codex subagents requested as gpt-6-luna, medium, fork_context=false. The tools accepted these request parameters and supplied agent IDs. Backend model identity, effective reasoning effort and token usage are not independently attested. No response was repaired, retried, replaced or selected from alternatives. Maximum open-agent count was four and every agent received close_agent after first-answer persistence.

Keep research-only. Do not recommend entering the proposed limited candidate-organization/human-review trial under this study's predeclared rule. Holdout contract validity is 15/20 (75%), below 90%, and one of two pre-labelled definite nonoffers is classified economic. Economic recognition is 15/16 (93.75%), meeting its 80% condition, but recognition alone does not satisfy the gate. The failed recommendation is robust to equivalent-label/boundary scoring limitations: contract and nonoffer conditions already fail.

The regression contract passes 23/49 (46.94%). Frozen core-complete counts are 3/49 regression and 0/20 holdout; they are not automatic map/publication rates. Only eight regression sources and one holdout source intrinsically supply both explicit-year campaign endpoints and positive physical scope within Description length limits. Core incompleteness therefore includes unavailable source facts, model provenance failures and frozen representation checks, not only extraction mistakes. The sole date-complete holdout has a source-equivalent venue-label mismatch under the frozen alias set, so its zero completeness credit is not proof of an incorrect venue.

These observations support only correction and subsequent independent review within the tested cohorts.
