# Frozen source selection and note authority

49 regression samples are copied byte-for-byte from benchmark-v4.sourceText. These are the existing complete isolated source envelopes, not entire website HTML pages. They participated in previous prompt/design review and are not unseen. Previously normalized single-line website strings retain that representation without additional normalization.

20 holdout samples are entire source.originalText strings from exports/review-inbox-2026-09-16/review-inbox.json, including original newlines, source footer and exact media-export marker. No linked pages are fetched; no text is cut around the correct offer. Context hints are null for every holdout. No selected text, URL or source SHA duplicates a regression sample; all four prior NLP benchmarks use the same 49-source cohort. The retained corpus was used in earlier deterministic ingestion work, which does not establish new-prompt holdout exposure or model-training independence.

The holdout has 18 distinct named merchants and one multi-merchant roundup source. McDonald's apostrophe variants count as one merchant. Coverage includes explicit 1–5 September 2026 steak-promos/The Capitol, unnamed selected outlets, missing-year dates, Subway/4Fingers/McDonald's exclusions, recurring weekday/time variants, a five-merchant roundup, incompatible outlet/date windows, product launch and closure article. Selection is purposive, not random or population representative. Only one holdout economic source has both explicit-year date endpoints; date generalization is correspondingly weak. Some holdouts overlap regression campaigns in another source family.

The separate evaluation-notes.json is parent-agent-authored source review, not human ground truth. Retained benchmark dates/roles/identities are inputs to this review; the new whole-source contract deliberately treats Early Bird and Bari salad groups as time variants while requiring abstention on independent Student Meal offers and unresolved mixed activity boundaries. Every note is fixed before extraction. Notes, parser output, old answers and correct boundaries never enter model messages. Aliases are comparison labels only and never rewrite model output or source identity.

Decision thresholds are fixed in spec.md. This cohort measures single-answer extraction, not repeat-sampling stability, source authority, official directories, coordinates or publication eligibility.
