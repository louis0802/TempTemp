# Intent — fresh date-first extraction evaluation

Validate whether the existing simplified campaign-date contract can reliably organize candidate promotions, reduce manual entry, and preserve every original limitation. This is a new model experiment, not rescoring of V4 responses. The complete source text becomes Description through deterministic copying. Research output cannot grant publication authority.

The affected users are researchers and potential human reviewers. Evaluate economic identity, explicit campaign validity, positive/excluded physical participation, core completeness and storage limits. Success means an honest reproducible experiment with source-grounded failure evidence and a bounded recommendation, not an automatic map-publication rate.

Use 49 existing full-source regression envelopes (previously exposed during design) and up to 20 distinct retained-source holdouts across at least five merchants. No fresh collection or duplicates to pad the holdout. Holdouts are unexposed to this prompt's tuning, not necessarily unseen by any earlier repository work or model training.

Exactly one new gpt-6-luna, medium, fork_context=false subagent per source; maximum four open agents and 69 extraction tasks. No retries, fallback, repair, answer selection, hosted API or repeated-sample stability study. Preserve previous experiments, frozen fixtures, annotations, first responses and the starting Git index.

Excluded: production ingestion/publication/persistence/registry/UI/migrations, database access, scheduling, deployment, commit/push and automatic continuation into another study. Report model/transport availability limitations instead of substituting a model or claiming unverified backend identity.

## Outcome

The authorized single-run study is complete: 69 new first answers, frozen/reproducible scores, raw provenance and detailed source error review. Results do not meet the predeclared limited-trial gate. Candidate-organization value remains a research question requiring contract/evaluation correction and independent review; no implementation or study beyond this run is authorized by this outcome.
