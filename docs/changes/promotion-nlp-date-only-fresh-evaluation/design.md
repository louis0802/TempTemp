# Design — isolated frozen full-source experiment

The repository's Promotion NLP module is research-only (docs/architecture.md section 12). Reuse date-only-profile.ts prompt/schema/validator and date-only-evaluation.ts read-only. Existing V4 evaluation demonstrates whitelist projection, exclusive writes, first-response persistence before JSON.parse, launch/task binding and seals. Extend these mechanisms in a new scripts/research runner and separate scorer without editing any prior implementation.

Build samples.json from benchmark-v4's 49 complete original source envelopes plus locally retained captures selected and reviewed before freeze. Preserve the exact supplied source string; any capture extraction recipe is explicit and hashed. Evaluation notes live in evaluation-notes.json separately from model input. Notes are parent-agent-reviewed references with original quotations and identity/alias sets, not human labels. Whole-source semantic review accounts for independent offers and time/weekday variants; no gold boundary enters tasks.

The runner freezes samples/notes plus imported validator/calendar/physical-label/schema modules, its own runner/scorer, prompt/schema and tests. Create per-task whitelist messages containing only prompt, schema, full text and merchant/title hints. Requested configuration is fixed at gpt-6-luna/medium/fork_context=false. The tool supplies an agent ID but no backend-model attestation or usage. Prompt-enforced tool abstention has no mechanical tool-denial parameter; this limitation is disclosed. Extraction agents must answer only and never read files, browse, call tools or delegate.

Before spawning reserve one exclusive task slot under a filesystem lock; bind the returned agent ID once. Record elapsed timestamps and the original wait result text exclusively, then close the agent and save closure evidence before freeing capacity. Audit intervals count open agents through closure, not response completion. Transport errors remain single-attempt records. Persist raw bytes before all parsing/validation. On global configuration unavailability stop dispatch and preserve missing tasks; no alternative model.

A final raw seal binds immutable manifest, tasks, attempts, raw responses and closure records. Verify frozen/protected hashes and unique task/agent identities before scoring. The scorer loads evaluation notes only after verification. It distinguishes execution, syntax/schema/contract acceptance, semantic identity/date/scope/role correctness and completeness. Date endpoints and annotated outlet identities each retain denominators even on failures; correctly unknown is separate. Aliases are scoring equivalents only. Benefit identity/qualifier checks use pre-frozen source-supported fragments. Description is copied independently of parsing and gets its own deterministic metric.

Historical comparison uses the existing replay.json read-only; only reviewed single-campaign full-source boundaries may pair with archived V4 units. Never compare 28/34 directly with whole-source rates. Outputs are results.json, failures.json, report.md, verification.md and decision.md in this new directory; raw records/seals/manifest are retained there for review. All output paths use exclusive writes for evaluative artifacts. No production/API/database dependency or package/startup hook is introduced.

A SHA-256 preservation snapshot taken before documentation covers existing src/scripts/tests/docs, migrations, prior NLP experiment directories and key root files, plus the Git staged diff. New documents can evolve before/after execution; frozen evaluative inputs cannot. Local rollback removes only this change's new files. No migration or deployment is involved.

## Implemented details and limits

Evaluative files are exclusive and frozen; report.md additionally receives an append-only diagnostic delivery index after scoring. error-review.md/json are separately labelled post-seal parent review and never alter results.json, the pre-frozen notes or the gate. The final delivery seal hashes both frozen scores and these diagnostics.

One collective all-Shack participant passes the inherited physical-label check. Two all-scope quotes are falsely rejected by the inherited merchant-dependent recognizer; two longer literal venue labels fall outside frozen aliases. These limitations are retained for this run rather than patched after seeing answers. Completeness also has an intrinsic source-date/scope ceiling (eight regression, one holdout). The dates/role/identity metrics keep different denominators and raw failures.

There are 28 historical-unit pairs from 26 sources; multiple old units can refer to one current whole-source answer and are correlated. Pairing is diagnostic only because routed conditional normalization and full-source classification/extraction differ. Title entailment is not separately quantified by the literal quote validator; the three frozen complete records were source-reviewed, and no publication authority follows.
