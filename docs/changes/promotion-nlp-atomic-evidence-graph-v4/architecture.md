# Architecture
Source → immutable evidence → proposition anchors → explicit target-set edges → publication taxonomy → local fact normalization. Each transition consumes sealed outputs. Stages1–3 use one fresh agent per surviving source; stages4–5 use one fresh agent per surviving proposition. Stage5 is generated only for economic_offer. All evidence stays as exact source nodes; no merged text bundle exists.
Only the orchestration parent invokes requested Codex subagents. The local runner stores task/launch/raw/seal files; it has no network/provider/database transport. Fresh agents receive literal prompts with a strict schema and allowlisted input. Tool isolation is prompt-enforced, not mechanically guaranteed by the spawn API; requested model/configuration is auditable, backend identity is unavailable.
Source-only Stage1 input is projected from the sealed V3 manifest, with captured-source byte verification. Model answers and gold never enter prompts. Stages2–3 see evidence in deterministically preserved source order, losing unrepresented prose context; grouping failure under this restriction is a measured architecture outcome.
Every stage seal binds raw bytes, tasks, launches, manifest and previous seal. First responses are stored before parsing; invalid upstream units produce blocked downstream tasks, never repaired. Final verification reprojections reproduce each downstream task file exactly and compares all protected file bytes.
