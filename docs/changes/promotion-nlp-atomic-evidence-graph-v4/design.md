# Design
Disconnected modules under src/ingestion/promotion-nlp/*-v4.ts and scripts/research/promotion-nlp-subagent-v4-evaluation.ts; no production imports. Zod strict objects reject extra bundles and invented IDs. Stage1 nodes have id/quote/kind and exact-source containment. Stage2 anchors reference existing nodes. Stage3 emits one assignment per evidence node with explicit target set and relation. Stage4 is one isolated proposition per agent; Stage5 only economic_offer, evidence IDs on facts and constraints, no synthetic evidence text.
Stage1-3 execution unit: source. Stage4-5: proposition. Inputs are constructed field-by-field; stages2-3 see all source evidence and competing anchors but no full source. Stage4-5 see anchors plus linked evidence/relations only. Source order is retained via immutable node offsets computed deterministically in tasks.
Local runner uses exclusive writes, immutable manifests, launch ledgers, first-response records and SHA256 seal chain. It has no provider/network/DB transport; the parent invokes Codex subagent tools with fixed configuration. Tool denial is prompt enforced because spawn supports no mechanical denial parameter; backend model identity is unavailable and must not be claimed. All generation reprojects from sealed upstream records, no repair.
Gold separates source-span coverage, anchor identity, allowed edges and normalized facts. Source-reviewed V3 annotations are a seed, not a blind execution input; atomic corrections and taxonomy review are frozen in benchmark-v4 before launch. Matching accepts exact source spans containing a required clause and documented alternatives, never paraphrase. Safety scoring preserves raw outcomes separately from structural rejection.
Publications, persistence, migrations and services are outside scope. Rollback: remove only new V4 research files; existing files unchanged. No running worker or scheduling.

Verified implementation: source order is derived by first exact-source offset and persisted as ordered nodes; models do not receive new synthetic scope text. Duplicate quotes intentionally fail whole-source validation. Stage5 reuses unchanged pure V3 clock/domain helpers and rejects whole invalid units, rather than partially accepting/reconstructing them. Final source review retains rejected raw records separately. One lexical false rejection and minimum-gold matching limitations are documented, not fixed inside the frozen run.
