# Evidence edge contract
Record {evidenceId, propositionIds, relation}. Frozen relations: benefit, validity, weekday, time, location, exclusion, participation, constraint, redemption, context. Exactly one record per evidence node expresses an explicit target set. [] is permitted for ambiguity/global context/unsupported association; genuine sharing is explicit multiple targets. Existing IDs, valid enums, unique target IDs and unique evidence assignments are deterministic requirements.
Stage3 sees all source evidence and all proposition anchors. It cannot reconstruct or rewrite evidence. Conservative omission is a recall failure; incorrect publication-critical association is a safety failure. Each target/relation pair is separately scored against frozen source review. Exclusions stay exclusion; contest submission dates never become meal validity; app-check/release Mondays are context or redemption-related, not availability weekdays. Price-variation statements never become positive branch participation.
Separate Bari location/time groups must not share group-specific schedule edges. Material edge recall uses the gold conditions that change eligibility/entitlement/redemption/quantity/timing/participation/exclusions; missing upstream nodes stay in end-to-end denominator. Edge precision and conditional recall denominators are stated separately. Structurally valid edges may be semantically wrong.
