# Normalization contract
Stage5 receives one economic_offer anchor, its linked immutable nodes and relations, no full source or sibling evidence. Fields merchant/title/benefit/startDate/endDate/weekdays/locationScope carry {value,evidenceId}; null facts use null evidenceId. Time constraints, location rules and constraints reference one local evidence ID. There are no quote/supportingQuotes/associationQuote/primaryProposition fields.
Benefit is verbatim source economic wording and retains From/Up to/selected-item/quantity qualifiers in benefit or material constraints. Merchant requires literal evidence; hints never establish it. Dates YYYY-MM-DD require source-explicit year, never inferred current year. Availability weekday arrays are Monday1-Sunday7, not operational check days.
Time union: range(start,end), before(time), after(time), opening_to(end). Every clock must be explicit; opening_to never synthesizes 00:00. Physical location rules have participating/excluded roles and literal names. Positive scope all_outlets/selected_outlets/named_outlets/null is independent of negative exclusions. Holidays, channels and generic all-outlets labels are not physical identities; price variation does not establish campaign scope.
Constraints {text,attributes,evidenceId} are source-verbatim local clauses with composable frozen attributes: purchase, audience, redemption_channel, redemption_action, social, timing, availability, reservation, frequency, item, exclusion. Flash/show a page/coupon/QR and enter a promo code use redemption_action; app/dine-in/takeaway/website use redemption_channel. Multiple attributes can apply. Material conditions are required even when also represented as dates/times/locations.
Constraint coverage traces node → correct edge → normalized meaning. Captured+linked Flash this page omitted in normalization is Stage5 loss. Structural validation rejects nonlocal IDs/text; scorer/source review, not schema, establishes semantic dates, clock meaning, taxonomy and polarity.

The V4 validator reuses unchanged V3 pure clock/domain helpers and the calendar check: it rejects unsupported clock endpoints, unstated local years, nonphysical labels, conflicting roles and channels used as positive scope. It rejects the whole invalid unit and never rewrites/filter-repairs raw output. Raw violations remain auditable; null downstream is not proof of model safety. These narrow checks cannot prove correct proposition association or offer participation.
