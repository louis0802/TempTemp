# Promotion NLP extraction foundation

Given an exact, trusted campaign text block, evaluate whether a general hosted LLM can extract the existing promotion facts without inventing unsupported facts. Users benefit from broader semantic coverage across merchant layouts; source authority, enumeration and campaign isolation remain deterministic adapter responsibilities.

Success means a vendor-independent evidence-bound contract, reviewed captured-text benchmark, deterministic validation, provenance-preserving candidate mapping, and reproducible offline/live evaluation. The principal KPI is `unsupported_fact_survived_validation`, especially validity, scope, outlet identity and hours. Target: zero; report actual results without lowering safety to improve recall.

This is research only. Preserve current extractors, direct-source-v2, publication, activation states, and existing workspace changes. No production DB writes, adapter migration, scheduler, OCR, media interpretation, Instagram acquisition, Telegram recollection, model training, commits or pushes. Live evaluation is authorized only with available configured credentials; do not request credentials or fabricate results.
