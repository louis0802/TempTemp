# Validator guarantees and limits

Validation is structural and evidentiary. It returns accepted fields, rejected original values/quotes with reason codes, issues, definite/uncertain classification and envelope validity. Malformed envelopes fail entirely; well-formed envelopes reject unsupported fields independently. Source whitespace is collapsed once, without case/punctuation/Unicode normalization. Quotes must be literal substrings of that normalized source. There is no fuzzy rescue.

Checks cover missing/nonmatching quotes, valid Gregorian dates and explicit quoted years, date ordering, unique integer weekdays 1–7, supported single hour ranges, exact outlet names inside their own supporting quote, named-scope/name coherence, explicit all-outlet wording and unrestricted all-outlet quotes. The all-outlet wording guard accepts literal all/our/merchant-context outlet phrases, not arbitrary 'all items at outlets'. Location/eligibility/redemption/terms lists retain verbatim source items. Non-promotion clears all facts. Uncertain and all mapped research records stay blocked by `promotion_nlp_research_only`.

The mapper repeats field validation and verifies source/evidence identity. It reuses newCandidate/cite/finalizeCandidate. Original evidence ID and selector survive; grouped validity/location provenance uses a literal covering source span. Full source text remains description so unsupported holiday/hour rules stay available for review. Registry merchant identity has an explicitly labelled configuration selector. Model identity cannot replace it; an explicit mismatch raises `nlp_merchant_conflict`.

Exact support is necessary, not sufficient. This validator does not establish whether a copied date belongs to the primary offer, whether a valid hour range normalizes the quote correctly, whether a mentioned outlet participates, or whether a scalar paraphrase is entailed. It does not prove DOM isolation or authority. In an adversarial replay, injecting the McDonald's contest dates as meal dates passes structural checks; scoring correctly reports two surviving critical facts. This is a documented limit, not a successful safety result. A second language engine or model verifier was deliberately not added.

Candidate schema compatibility and the research blocker do not authorize adapters to use NLP. Production publication, ingestion and direct-source-v2 remain unchanged. Benchmark-only readiness is appropriate until live semantic evidence and these failure classes are reviewed.
