# Intent

Discovery source → PromotionSignal → Source evidence → Future canonical promotion.

Telegram posts currently become separate MVP promotions even when they describe the same campaign. Preserve these useful discovery claims while recording linked sources that may later support canonical facts and matching. Users of this first layer are ingestion maintainers and future reconciliation tools; public visitors see no change.

Discovery means where a claim was found. Authority means deterministic ownership evidence for a linked source. Canonical identity means whether claims describe one real offer; authority alone does not establish it.

Success: curated posts produce reproducible, explainable evidence with safe redirect expansion and conservative authority classification. Preserve the 200-record MVP artifact, public behavior, existing parsers, Google resolution, publication and review flows. Exclude canonical merging, open-web search, page fact extraction, fact replacement, public badges, scheduling and remote changes.
