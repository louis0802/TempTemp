# Design

A standalone `src/ingestion/source-evidence/` module reuses PostOfferParser, DateResolver and OutletScopeResolver directly. Signal granularity follows parser offers, not MVP-specific presentation/window expansion. Thus signal count need not equal the preserved 200 MVP records. No existing parser or public application code changes.

Types distinguish PromotionSignal, SourceLink, resolved links, registry and evidence graph. Hash identity uses source URL + parser key, with evidence IDs using signal ID + normalized link. Dates remain hints, including parser issue diagnostics. Links scoped only to the enclosing post remain explicitly post-level. Source permalink is its own discovery evidence node.

Registry version 1 holds normalized merchant keys, exact primary domains, exact social host/account identities and merchant-specific secondary domains/kinds. It starts empty rather than inventing ownership. Social hosts cannot be promoted by a domain-only rule. Known Telegram channels are globally classified as discovery; known editorial hosts use a small explicit list.

Network safety: CLI reads the fixed trusted curated export, derives an allowlist from extracted links, and resolver denies other starting URLs. No public endpoint or arbitrary corpus/URL CLI option. Every redirect is manually validated. Only HTTP(S), no credentials, only default ports, no localhost/local names. DNS checks all returned addresses, rejects mixed public/private answers, and pins a checked address into Node's request lookup to prevent DNS rebinding. HTTPS retains hostname/SNI validation. IPv4 special/private/reserved ranges and the Azure platform virtual IP 168.63.129.16 are denied; IPv6 uses a conservative global-unicast allowlist excluding special/documentation/transition ranges. No proxy, cookies, auth or caller headers; fresh agent-free connections. HEAD first, GET only for 405/501, discard response immediately after headers without page parsing. Response headers capped at 16 KiB; GET sends a 1 KiB Range hint and immediately destroys the stream (zero retained body bytes), even if the server ignores Range. Five redirects and ten seconds total including DNS and fallback. Abort cancels requests; DNS promises may finish after abort but cannot initiate a request. Redirect errors preserve the chain and reason.

JSON disk cache keys are normalized original URLs; checkedAt comes only from resolved attempts and never participates in IDs. Offline misses have null checkedAt. No implicit expiry or failure retry; deleting a reviewed cache entry permits retry. Cache files and artifact are atomically replaced. Fixture transport supports deterministic safe-network tests without contacting external services. Production cache and fixture outputs are separated.

Authority is based only on successfully resolved destinations; unresolved links remain unknown except independently recognized discovery source nodes. Page content is never downloaded for extraction or used to alter facts. A registered host establishes ownership, not campaign relevance or fact verification. Future matching consumes resolved URLs without changing this layer.
