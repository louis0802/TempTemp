# Design
Retain MerchantOutletProvider → PromotionParticipationResolver → ApiPlaceResolver → PromotionEligibilityService. Reuse ResolutionCache and bounded fetchText with injected fetch. GoogleOutletDiscovery stays non-authoritative. Default registration changes only after dedicated provider regression tests pass.
A deterministic reporting script uses the existing conservativePipeline, original deduplicated source text and fixed 2026-09-17 evaluation time. Store offer identity, merchant, action, reasons and outlet audit; aggregate observed unresolved reasons without inventing downstream failures. Conservative corpus remains intentionally independent of live providers; any additional fixture-backed coverage comparison must be separately labelled.
Select official sources by the report's directory-blocked counts. Document traversal contracts from inspected official markup/JSON before implementing an adapter. Shared utilities should capture audited source metadata and validate enumeration invariants, not infer completeness from mere HTTP success. No database/schema/transaction changes. Provider registration can be rolled back independently.
Review coordinates and selected-outlet linkage after directory work; change only on demonstrated source evidence/failure with offline regression coverage. Current place matching rejects ambiguity/status conflicts and preserves building precision; selected list retrieval requires exact source linkage.
