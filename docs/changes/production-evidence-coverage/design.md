# Design
Retain MerchantOutletProvider → PromotionParticipationResolver → ApiPlaceResolver → PromotionEligibilityService. Reuse ResolutionCache and bounded fetchText with injected fetch. GoogleOutletDiscovery stays non-authoritative. Default registration changes only after dedicated provider regression tests pass.
A deterministic reporting script uses the existing conservativePipeline, original deduplicated source text and fixed 2026-09-17 evaluation time. Store offer identity, merchant, action, reasons and outlet audit; aggregate observed unresolved reasons without inventing downstream failures. Conservative corpus remains intentionally independent of live providers; any additional fixture-backed coverage comparison must be separately labelled.
Select official sources by the report's directory-blocked counts. Document traversal contracts from inspected official markup/JSON before implementing an adapter. Shared utilities should capture audited source metadata and validate enumeration invariants, not infer completeness from mere HTTP success. No database/schema/transaction changes. Provider registration can be rolled back independently.
Review coordinates and selected-outlet linkage after directory work; change only on demonstrated source evidence/failure with offline regression coverage. Current place matching rejects ambiguity/status conflicts and preserves building precision; selected list retrieval requires exact source linkage.

## Proven first provider: Papi's Tacos
The official https://www.papis-tacos.com/ HTML explicitly declares four locations. Four server-rendered `.image-card` entries provide branch labels, full source addresses and seven weekday schedules; the unique header navigation `*-home` links independently enumerate the same four names. No pagination is present. Use the explicit count, unique branch/address checks, navigation/card equality, closed document and absence of continuation controls as the traversal contract. Reject markup/count/status drift rather than infer completeness. Preserve the official `149 Tyrwhitt Roard, 207562` typo verbatim; do not silently normalize physical identity. Country scope is the official Singapore-only site and its welcome text, backed by Singapore-format postal codes. Foreign country labels block the snapshot.
Reusable `official-directory.ts` fetches/caches fixed official URLs with audited hashes and validate count, duplicates, provenance and traversal proof. Dedicated Papi parser owns markup semantics; runtime provider rejects invalid snapshots even for named scopes. Keep Genki unchanged. Runtime cache TTL remains one hour. No coordinates are extracted from map imagery; ApiPlaceResolver must independently establish them.
Captured Papi fixture improves directory evidence for two original offers in a separately labelled offline comparison; coordinates remain deliberately unavailable, so no approval is claimed. The conservative baseline corpus retains its existing provider set.
