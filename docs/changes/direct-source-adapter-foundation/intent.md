# Intent: direct-source adapter foundation

Acquire authoritative candidate evidence directly from verified Pepper Lunch Singapore and Paradise Group surfaces. The existing production acquisition path assumes Telegram source posts, numeric message IDs and Telegram-only promotion URLs; forcing website content into that path would lose source identity and evidence. Telegram remains signal-only; direct-source evidence is authoritative candidate input.

Deliver a small production-capable source-specific crawling boundary, deterministic normalized candidates, reproducible offline fixtures and a one-shot bounded shadow preview. Success means both domains use the same acquisition contract while keeping their distinct semantics, unknown facts and coverage limitations visible.

Constraints: no DB/publication/reconciliation, no geocoding, no scheduler/monitor/worker, no revision-6 research, no Telegram replacement or fabricated SourcePost, no generic web crawler, no LLM/OCR, no commit/push. Existing production ingestion, merchant registry and all research/monitor artifacts remain unchanged. Read existing captures; write new evidence only under a dedicated ignored preview directory.
