# Specification
1. Revision 4 applies only to new intervals; retain revision 3 and its registry for reproducibility. September 25 remains rehearsal/non-scoring.
2. Each channel has hourly scheduled slots. Retain slot, attempt, completion, raw outcome and lateness. Distinguish on-time success, late success, failed and missing. Five minutes is the inclusive tolerance for successful observation completion; attempt lateness is separately retained. Baseline must precede the interval. Missed/offline slots cannot be backfilled. A new interval opened by an already running service within tolerance is not a late-start rehearsal; a fresh service after midnight is.
3. Explicit cadence: five dated publisher/index sources every three Singapore wall-clock hours; remaining directories/campaigns daily. Preserve source-specific caps and limitations. Acquisition observation windows allow completion before the next scheduled source slot; crossing the daily boundary is incomplete.
4. Repeated candidates retain earliest independent first_seen_at and every distinct source occurrence. Merge all same-day passes once at close, freeze before any matching. Identity is conservative; merchant equality is not offer equality.
5. Tracker reads research files only, computes counts, current stage, health, adapter maturity, gaps and gates. Missing state/review returns unknown or insufficient_evidence, not invented zero success. Sealed scored intervals require verified seals. Rehearsal matches may be labelled observations only.
6. Initial checkpoint requires three complete synchronized **revision-4** scored days and a meaningful benchmark sample. Earlier scored revisions remain visible as historical evidence but never advance this revision-4 gate. Because no justified sample minimum is agreed, sample sufficiency remains an explicit researcher-review gate; nonzero offers alone never satisfy it. Preferred checkpoint is five to seven valid days and a materially larger sample. Recall .80, precision .95 and fact completeness .70 are exploratory targets, not production decisions.

Acceptance: fixture tests cover jitter (4ms, 2s, 4m), late (6m), missing/failed/offline/restart; tiered multipass merge/freeze; no-state/rehearsal/partial/sealed/multiday tracker; source adapter reporting. Run research + Telegram preview tests, typecheck, scoped lint and diff check. Compare protected file hashes.
