# Architecture

Captured isolated source → fresh Stage 1 → sealed exact proposition units → automatic allowlisted tasks → fresh Stage 2 per unit → sealed extraction outputs → annotation scoring and parent source review. There is no primary campaign selection. Stage-2 facts cannot cite omitted/sibling strings; Stage-1 attachment and Stage-2 semantic errors are measured separately. Context hints may inform understanding but never provide evidence.

Execution: 49 source agents →47 usable segmented sources →78 automatically projected units →78 fresh extraction agents →68 schema-parseable outputs. Two exact-span source failures receive no extraction tasks; ten extraction failures are not repaired. Both provenance seals verified after source review. The boundary makes error attribution observable but does not enforce correct Stage-1 semantic grouping or local classification.
