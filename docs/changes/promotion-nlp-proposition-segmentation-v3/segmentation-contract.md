# Segmentation contract (frozen before execution)

Output: propositions [{id, propositionQuote, supportingQuotes}], unassignedQuotes. IDs are unique, short stable labels supplied by the agent; original array order is retained. Zero through eight units. Every quote is a nonempty exact contiguous normalized-source substring. No paraphrase, synthetic concatenation or truncation. A unit centers on one independent activity/economic proposition; associated terms can be separate exact spans. Related variants may stay together when terms retain correct scope. Independent editorial/contest/offer activities split. Ambiguous relevant clauses remain unassigned. Shared terms may be copied into multiple units only when the source clearly applies them to each.

Structural or exact-span failure rejects segmentation as a whole; it is separately reported from JSON syntax failure. Gold matching uses reviewed alternative central anchors, not exact output string equality. A boundary difference is harmless when expected propositions remain independently recoverable with correct terms. Merges match two independent anchors in one unit. Harmful splits distribute indispensable terms across units so no complete economic proposition is recovered. Broad editorial extras are reported separately from safety failures.
