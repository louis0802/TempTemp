# Decision

Retain **A**. **A2 is not justified**. All 49 fresh gpt-6-luna tasks ran, but two real excluded-outlet participation errors survived validation, and a secondary-campaign end date was promoted to validity. The unchanged scorer flags 18 critical survivors in total. Many exact-match discrepancies are source-supported wording/grouping differences; that does not remove the actual safety failures.

The McDonald's contest-date safeguard passed naturally: startDate and endDate were null. Sushiro did not invent a year. Bari remained within isolated cards, but one of five outputs was malformed. Captain's five layouts classified correctly and four venue cases extracted dates correctly, but student/minimum-party/lowest-paying-diner constraints were dropped or rejected. Classification also promoted ordinary Sushiro/Zi Char product text and both ambiguous Shake Shack activity/editorial cases. Failures were therefore not uniformly conservative.

Next investigation: prompt-v2 with explicit positive versus excluded outlet roles, primary versus secondary campaign association, verbatim quote/list discipline, and stricter separation of product launches from economic incentives. Investigate evidence segmentation for mixed editorial/contest texts, and schema role definitions for eligibility/redemption/terms and excluded outlets. Test new prompts on fresh held-out sources in a separate slice; do not adapt merchant regexes to these answers. No fixes were made to prompt-v1, schema, validator, benchmark gold, or adapters during this run.

An API-model benchmark would eventually be justified as a separate portability/reliability study, **not the immediate next readiness step**. First investigate these semantic and output-contract failures. This run validates no production API model and authorizes neither hosted calls nor B/C/D. B = API shadow evaluation; C = new adapters using NLP; D = replacement of deterministic extractors. All remain unauthorized. No production enablement, acquisition, DB work, activation, commit, or push occurred in this repository.
