# Methodology

Executed on 2 October 2026 (Asia/Singapore). This evaluates Codex **gpt-6-luna subagent semantic capability**, not production OpenAI API model reliability. Each case received only a new allowlisted source/hint object, v1 instructions, and schema. No forked history, benchmark answers, parser outputs, prior answers, scoring feedback, chain-of-thought request, retries, or semantic repair. Tools were expressly prohibited in each extraction prompt; the spawn capability does not mechanically disable tools or deny filesystem access. Isolation is fresh conversation context plus prompt/input boundaries, not a claimed filesystem sandbox.

Used bounded concurrency four, one first response per case. All 49 agents were created with fork_context=false, model=gpt-6-luna, reasoning_effort=medium. Completed agents were closed. Raw output was saved verbatim with exclusive writes before parsing. All 49 responses were sealed and their hashes checked before gold loading. The parent read prompt/schema/validator/scorer code and sanitized source prompts beforehand, but did not read gold values, checked provider outputs, or parser answers until the seal. Existing validator/scorer remained unchanged; all 49 stayed in denominators. Source review followed scoring, with all 18 critical survivors listed separately from official exact-match metrics.

Explicit requested model: gpt-6-luna for all 49, accepted by the spawn tool on every launch. No fallback, model mixing, answer retries, or other judging agents. Runtime backend/revision identity beyond the requested and accepted configuration was unavailable. There were 49 raw responses, five JSON syntax failures, and zero execution errors. All five syntax failures had an extra closing brace; none was stripped or reparsed after repair.

Gold-relative unsupported counts use the existing canonical exact/list comparison. They include merchant suffix/capitalization, shortened benefit/title wording, list omissions, and different field grouping; they are not counts of independently proven hallucinations. The 18 official critical survivors comprise two excluded-outlet role errors, one secondary-campaign date association, six scope values supplied where the reviewed contract requires null, eight eligibility grouping/coverage discrepancies, and one outlet-label normalization discrepancy. Keep official totals unchanged. A valid copied quote does not establish its semantic role.
