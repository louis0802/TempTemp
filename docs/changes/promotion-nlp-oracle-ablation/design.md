# Design

Research-only TypeScript modules under src/ingestion/promotion-nlp and scripts/research. Reuse unchanged V4 Zod schemas, prompts and structural validation where applicable. The new oracle-ablation module owns projection, opaque mapping, frozen task construction, equivalence-aware scoring, oracle sanity, ceilings and diagnostics; deterministic-spans owns offline literal segmentation. A disconnected CLI owns preparation, exclusive launch/record persistence, seals, verification and report artifacts. Model transport is the existing Codex spawn/wait/close API controlled by this parent; no provider import or network fallback.

Private semantic mapping stays in scorer artifacts. Agent inputs are whitelist projections with opaque case IDs, neutral merchant/title hints, eNNN/pNNN IDs, and exact allowed evidence. A sees evidence only; B adds neutral propositions; C gets isolated reviewed graph; D adds economic_offer and no sibling evidence; E sees only deterministic nodes. No arm consumes another arm's result.

Equivalence: exact canonical clause matches take precedence over alternative matches to prevent overlapping/colliding reviewed alternatives creating spurious edges. Literal containment and reviewed alternatives accept boundaries; anchor punctuation boundaries may use reviewed clause alternatives. One-to-one identity matching identifies merges/splits separately; coarse relations accept only frozen allowed alternatives. Constraint facets may compose across literal records for the same source-backed clause. Null/date/weekday/time/location expectations and polarity are independently assessed. Annotated normalization control omits unannotated merchant/title/benefit values, carrying qualifier proof separately.

C1 requires literal acceptable anchors/constraint text; C2 additionally independent identity; C3 additionally correct ownership (economic identity needs an owned anchor); C4 additionally economic eligibility. Stage5 survival uses annotated fact/constraint matching, reporting structural rejection separately. All ceilings are benchmark-relative text/identity/ownership recoverability, not proof of complete source truth. Freeze these rules before execution.

Snapshot all preexisting substantive files/prior runs before writing; validate prior V4 seals using its read-only verifier. Prepare an immutable manifest with benchmark, projection, new implementation, prompts/contracts, tasks, protected/prior bytes. Each arm seal binds manifest, tasks, launches, raw, and individual records. Exclusive writes prevent repairs; registration guards uniqueness and at-most-four unresolved launches globally. Infrastructure failure does not relaunch. Rollback is deleting only new study files; no migration or rollout.

Prelaunch ceiling reconciliation: primary ceilings preserve the existing source-review identity adjudications and its 228-condition optimistic upper-bound audit, tied to sealed raw bytes and source hashes. A separately retained literalControlCeilings shows the stricter new matcher. This avoids misrepresenting frozen exact-boundary misses as new semantic losses. No V4 score or prior review is modified. Economic C3 uses reviewed local eligibility recoverability; C4 uses real recorded classifications.
