# Design
Add a pure structured search module and GET /api/mvp/search. Server reads current artifact, uses visibleMvp and mvpPreviewOptions, returns explicit safe result DTOs (no descriptions). Ranked results contain kind, id, label, context, promotion IDs and coordinates. Merchant targets include every eligible promotion for that normalized identity; location identities reuse groupMapLocations without changing it.
Explorer owns BrowseContext (map/place/nearby), merchant filter and selected promotion. A dedicated search component merges artifact and existing /api/places requests with independent outcomes, 250ms debounce, AbortController and stale-result guards. Native buttons provide keyboard selection; labelled sections distinguish types. Known location names deduplicate identical external labels conservatively.
PromotionMap reports user-origin movement separately from viewport emissions, preserving internal fitBounds context; merchant IDs add highlights without changing grouping. Selected detail may load before viewport results. Fit extrema of all target coordinates with margin. Native details/summary exposes provenance.
No database/artifact migrations, dependencies, scheduling, or publication changes. Rollback is a local code revert.

## Final interface and behavior
GET /api/mvp/search?q=<2–100 trimmed characters>[&includeExpired=true|&view=corpus] returns `{ items: SearchResult[] }`, at most five each of merchant/deal/location. Results contain kind, id, label, context, promotionIds, points (`lat`, `lng`) and numeric rank. No pagination or viewport argument; an incidental bbox cannot restrict search. Invalid query returns 400; artifact failure returns 503; responses are no-store. Production ignores both preview modes via the unchanged shared gate. showSourceText has no effect. The client separately merges up to five /api/places results, suppressing identical normalized artifact location labels. Sections follow the best-ranked result in each kind, with ranked rows within sections.
Merchant/deal selection uses a 0.006-degree margin around all locations, constrained to existing Singapore bounds. Merchant selection retains Map area context and visibly filters the loaded sidebar/pins, with Clear. Place selection uses its explicit label; geolocation uses nearby state. Actual user-origin MapLibre move events clear context; fitBounds/resize emissions only refresh viewport data. Keyboard pan and navigation-control zoom are browser-tested.
Search selection returns focus to the search input before opening a detail; stale detail responses are ignored. Long deal location summaries display two names plus the remaining count. Native details keeps disclaimer text in the accessibility tree when expanded; the existing compact map notice remains intact.
