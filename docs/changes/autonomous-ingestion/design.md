# Design
Extend the existing resolution modules and database service; do not replace architecture. Add a default-blocking issue policy with a narrow informational allowlist and persist classified issues in resolution audit. Strip the exact export marker only for material-media detection. Keep source terms verbatim. Parse titles without leading link wrappers and bound roundup sections before channel export footer; promotional roundup context can establish deal intent but cannot supply dates, locations or restrictions.
Add optional nullable redemptionCutoff to schema/date output/fingerprint/schedule label. Validity still requires a known hours interval before claiming redeemability, and respects cutoff when both exist. Match street-address selectors with exact normalized street address boundaries, keeping unit matching. Strip plural outlet suffix only for exclusion selectors and record each matched selector. Keep chain authority checks unchanged.
Derive suggestion UUID from source URL, source hash and offer key using SHA-256 UUID version 8 formatting; do not touch outlet identity. Service derives terminal outcome after reconciliation issues are known. Bump parser to v7. Keep Sushiro unresolved with requires_split: source does not allocate merchandise to waves.
Testing uses captured locator and mocked evidence only. No new migration is needed: promotion JSON supports an optional field and attempts outcome is free text. Existing records retain prior fingerprint shape when cutoff is absent. Rollback code/parser together; do not replay operational data as part of this work.

Final details: recognized channel signatures may contain only known feed metadata; unknown @handle footer content remains present and adds a default-blocking ownership issue. Numbered parsing also recognizes 🔟. Corpus tests use original-line section boundaries as a separate no-leakage oracle. Mixed terminal service outcomes use `completed`, with no database migration. Approved source reconciliation can still downgrade an attempt to needs_review; completed reviewer decisions continue to bypass reprocessing.
