# First multi-merchant direct-source batch

Onboard FairPrice, Kris+, Dian Xiao Er and CS Foods independently, using official public evidence rather than historical Telegram offer text. These four source families test retail campaigns, a partner platform, Wix campaign cards and a sale catalogue. Useful autonomous acquisition should reduce manual discovery without weakening promotion publication rules.

Each merchant ends in exactly one evidence-supported state: **enabled** (all activation requirements demonstrated), **shadow** (useful deterministic adapter, unresolved activation blockers), or **blocked** (no safe acquisition adapter justified). A blocked merchant is a valid result and does not delay the others.

Success means auditable bounded research for all four, production adapters only where justified, immutable offline replay and conservative candidate facts, preserved existing behavior, and a frozen-input merchant map with 139 rows. Enabled sources require disposable-database verification. Source ownership, complete enumeration and candidate completeness are separate assessments.

Constraints: preserve direct-source-v2, existing schema/persistence/publication/review, global network protections and existing evidence. No OCR, private/mobile APIs, access bypass, generic merchant crawler, scheduler, worker, Telegram recollection, Paradise/Gourmet activation, production/shared DB ingestion, commit or push.

Assumption: missing facts remain unknown and reviewable; successful access or complete product enumeration alone never establishes campaign validity or physical participation. Research findings determine implementation scope.
